# V4 40K Pair 数据审计报告：离线 BT 与答题行为外部一致性

> 审计日期：2026-08-06
>
> 审计对象：V4 的 10,000 道候选训练题、40,000 条候选比较边，以及最终教师有效 pair。
>
> 审计结论：**有条件通过（CONDITIONAL PASS）**。29,961 条最终有效 pair 已足以进入学生模型训练；但训练题节点口径必须从 10,000 道修正为 9,987 道。答题行为数据已完成可用性清洗，只作为外部一致性审计，不进入当前主训练损失。

本报告记录两条彼此独立的审计链路：

1. **离线 Bradley-Terry（BT）审计**：只使用最终教师 pair 的 soft target，检查比较图能否稳定支持一个全局难度排序；
2. **答题行为外部审计**：只使用真实作答次数和正确率，检查其与 BT 排序、教师 pair 方向是否具有一致性。

两条链路都明确禁止把上游绝对 `difficulty` 当作监督目标或审计依据。

### 1.2 两类审计各自不做什么

离线 BT 不读取题目文本、Aux11 特征、学生模型输出或原始绝对难度档位；它只回答“现有教师比较边是否支持稳定的一维排序”。

答题行为审计只读取 `question_id`、`parent_id`、`stem`、`structure_type`、`answered_count`、`percent_correct` 和 `sub_questions`。源文件虽在全部 231,406 条记录中均包含 `difficulty`，但报告明确记录：

```yaml
source_difficulty_used: false
```

因此，行为审计不会复用旧绝对难度，也不会以它验证教师 pair。

这里的 14 个连通分量并不表示存在 14 个大题群：它是 **一个 9,987 节点的大连通分量，加上 13 个零度孤立节点**。因此现有有效边本身没有形成多个互不比较的大簇；问题仅在于 13 道题的所有候选边均被位置偏差规则隔离。

离线 BT 报告因此给出 `REVIEW`，唯一实质门禁失败为“预期 10,000 节点未完全覆盖”。其余图完整性检查均通过。

### 2.2 训练数据口径

学生训练读取的是 pair 行；13 个零度节点不会出现在任意有效 pair 中，也不会产生 BT 或 Aux11 损失。因此可训练的真实节点集合是：

$$
\mathcal Q_{\mathrm{train}}=
\{q:\deg(q)>0\},\qquad
|\mathcal Q_{\mathrm{train}}|=9{,}987.
$$

后续 manifest、训练报告、Aux11 覆盖率审计都必须按 9,987 道题表述。原始 10,000 道选题清单仍保留，用于追溯 13 个被剔除节点；但不能继续将其称为最终训练节点数。

## 3. 离线 Bradley-Terry 审计

### 3.1 模型和交叉验证协议

为每道题学习一个均值固定为零的难度标量 $s_i$。对于 pair $(A,B)$，BT 预测为：

$$
\hat p_{A>B}=\sigma(s_A-s_B)
=\frac{1}{1+\exp[-(s_A-s_B)]}.
$$

其中教师 soft target 为 $y_e$、监督权重为 $w_e$。拟合目标为：

$$
\mathcal L_{\mathrm{BT}}
=-
\frac{1}{\sum_e w_e}
\sum_e w_e
\left[y_e\log\hat p_e+(1-y_e)\log(1-\hat p_e)\right]
+\lambda\lVert s\rVert_2^2.
$$

交叉验证采用保持连通的 5 折边划分：固定 9,986 条生成树骨架边留在每一折训练集中，再对冗余边做折分。这样可评价“未见比较边”的预测，而不会因为验证时图断开而人为失败。

### 3.2 主要结果

| Held-out 指标 | 离线 BT | 常数概率基线 | 结论 |
|---|---:|---:|---|
| 留出边数 | 19,975 | 19,975 | 5 折均完成 |
| Soft pairwise log loss | **0.5204** | 0.6848 | BT 更低 |
| Brier score | **0.0378** | 0.1178 | BT 更低 |
| Pairwise accuracy | **88.24%** | 58.88% | BT 更高 |
| Pairwise AUC | **0.9560** | 0.4925 | 接近随机的基线被明显超越 |
| 加权 pairwise accuracy | **89.72%** | 59.59% | 高可信边表现更好 |
| 加权 log loss | **0.5031** | 0.6832 | 高可信边改善仍成立 |

全量拟合的 accuracy 为 97.61%，但它是训练内拟合结果，只用于检查优化是否收敛，**不能**作为数据泛化质量指标。质量判断应以表中的 held-out 指标为准。

### 3.3 稳定性、残差与负对照

| 检查 | 结果 | 含义 |
|---|---:|---|
| Bootstrap 次数 | 20 | 固定生成树 + 冗余边重采样 |
| 平均 / 最低 Spearman | 0.9614 / 0.9593 | 题目整体排序稳定 |
| Top 10% / Bottom 10% 重叠 | 0.8035 / 0.7635 | 两端题目相对更稳定，但不是完全固定 |
| 全量边残差中位数 / P95 | 0.0646 / 0.2232 | 大多数教师 soft target 可被一维尺度解释 |
| 严重残差率，阈值 $|y_e-\hat p_e|\geq0.5$ | 0 / 29,961 | 无极端自相矛盾边 |
| 打乱 soft target 后 held-out accuracy | 50.05% | 排序信号在随机对照中消失 |

边残差定义为：

$$
r_e=\left|y_e-\sigma(s_A-s_B)\right|.
$$

负对照中，打乱教师 soft target 后的 held-out log loss 上升到 0.8944、Brier 上升到 0.1864、AUC 降至 0.4966。这说明当前 BT 结果不是图规模、类别不平衡或固定代码路径制造出来的表面高分。

### 3.4 构边策略的审计解释

`feature_contrast` 的 held-out accuracy 为 97.59%，而 `feature_near` 为 77.84%。这符合构边设计预期：特征差异明显的跨度边更容易形成稳定全局尺度；特征相近的近邻边本来更难，但仍显著优于其常数概率基线。

因此，当前图混合了“用于确定尺度”的信息量大边与“用于刻画细粒度排序”的困难边，而不是只选择容易被教师判断的 pair。

### 3.5 BT 审计结论

离线 BT 给出如下结论：

- **有效 pair 的内部排序质量通过**：交叉验证、稳定性和打乱标签负对照均支持该结论；
- **最终图覆盖需修正后再开训**：13 个零度节点从训练节点口径中移除，或另行补充可靠边；
- **不建议为修复覆盖直接恢复高位置偏差边**：这会重新引入最终清洗明确剔除的噪声。

该结果仅证明教师 pair 图的自洽性与可排序性，不能直接证明全局难度等同于真实教研难度。

## 4. 答题行为数据质量审计

### 4.1 从正确率到行为难度

对一道题 $j$，设作答次数为 $n_j$、报告正确率为 $r_j$（百分比）。若该比例可精确还原为整数答对人数，则使用整数 $c_j$；若无法还原，例如多选、主观、部分得分或分母口径不同，则保留连续伪计数：

$$
\tilde c_j=n_j\frac{r_j}{100}.
$$

使用 Beta 先验 $(\alpha_0,\beta_0)=(1,1)$ 得到正确率后验：

$$
\theta_j\mid c_j,n_j
\sim
\operatorname{Beta}(\alpha_0+\tilde c_j,\;\beta_0+n_j-\tilde c_j).
$$

定义“更大表示更难”的行为难度标量：

$$
b_j=-\operatorname{logit}\left(\mathbb E[\theta_j]\right).
$$

连续伪计数不是伪造整数答对数：它保留报告正确率的信息，但 `behavior_evidence_quality` 设为 0.5。整数精确恢复题质量为 1.0，存在多个整数候选时为 0.85。

### 4.2 V2 清洗结果

| 项目 | V2 结果 |
|---|---:|
| 原始记录 | 231,406 |
| 接受的唯一题目 | **230,952** |
| 真正无效 / 隔离记录 | **454（0.20%）** |
| 整数精确恢复 | 189,684 |
| 连续伪计数保留 | 41,253 |
| 多整数候选 | 15 |
| 作答次数中位数 / P90 | 106 / 727 |
| 作答次数均值 | 285.20 |
| 正确率中位数 / 均值 | 74.18% / 71.20% |

V1 曾把 40,722 条“不能精确反推整数答对数”的记录视作无效。V2 改为保留其中 41,253 条连续正确率证据，因此有效题数由 190,684 提升至 230,952，而真正无效记录仅剩 454 条。

该修正不会把连续正确率当作高可信教师标注：它们在加权统计中降低权重，且不允许参与后文的高置信冲突自动判定。

## 5. 行为数据与 BT / 教师 pair 的外部一致性

### 5.1 覆盖率

| 指标 | V1 | V2 |
|---|---:|---:|
| BT 节点与行为数据重合题 | 1,236 | **1,576** |
| BT 节点行为覆盖率 | 12.38% | **15.78%** |
| 两端均有行为数据的教师 pair | 488 | **793** |
| 教师 pair 行为覆盖率 | 1.63% | **2.65%** |

V2 清洗显著提升了可参与审计的题数，但 2.65% 的双端 pair 覆盖仍然偏低。行为数据当前足以提供独立信号，尚不足以代表性地覆盖整张 V4 比较图。

### 5.2 题目级排序一致性

| 指标 | 数值 | 解释 |
|---|---:|---|
| 重合题数 | 1,576 | 行为分数与离线 BT 分数均存在 |
| Pearson | 0.3669 | 存在中等正线性相关 |
| Spearman | **0.3808** | 存在中等正排序相关 |
| Kendall $\tau_b$ | 0.2634，$p=2.65\times10^{-55}$ | 方向一致性显著高于随机 |

相关为正意味着：BT 更难的题，在真实作答中通常也更低正确率；但相关远低于 1，说明两者不应互相替代。真实正确率还同时受到学生群体、题目曝光时间、猜测、题型、给分方式等因素影响。

### 5.3 Pair 级方向一致性

对行为数据两端均覆盖的 pair，以两个 Beta 后验的差异近似计算行为侧概率 $p^{\mathrm{beh}}_{A>B}$。该概率表示“从真实作答表现看，A 比 B 更难”的不确定性判断，不是教师再次比较的结果。

| 指标 | 结果 |
|---|---:|
| 双端覆盖 pair | 793 |
| 可比较的硬方向 pair | 788 |
| 教师 - 行为方向一致率 | **64.21%** |
| 平均软 target 差异 | 0.3536 |
| 高置信可比较 pair | 299 |
| 高置信方向一致率 | **67.22%** |
| 高置信严重冲突 | 98 / 299，**32.78%** |

高置信门槛为：教师与行为概率均落在 $[0,0.2]$ 或 $[0.8,1]$，且两端行为数据质量均至少为 0.75。因此连续伪计数题默认不会被用于“严重冲突”结论。

98 条严重冲突是优先复核队列，不是“教师标签错误率”。例如，简单题若被低水平群体大量作答，正确率可能偏低；具备强套路或大量猜测的题目，也可能出现高正确率但教研难度不低。

### 5.4 按构边来源切片

| Pair 来源 | 行为覆盖 pair | 方向一致率 | 平均软 target 差异 |
|---|---:|---:|---:|
| `feature_contrast` | 229 | 72.93% | 0.3021 |
| `structure_matched` | 78 | 72.73% | 0.2970 |
| `graph_bridge` | 12 | 66.67% | 0.3404 |
| `low_degree_repair` | 47 | 63.04% | 0.3796 |
| `lexical_near` | 75 | 61.33% | 0.3705 |
| `random_global` | 158 | 60.76% | 0.3674 |
| `feature_near` | 194 | 54.45% | 0.4138 |

`feature_near` 是一致性最低的切片，符合其设计目的：它刻意比较辅助特征接近、难度差更细微的题目。该发现支持保留该类边用于细粒度排序，但不应把它与明显跨度边期待为同样容易判定。

## 6. 综合审计结论与训练门禁

### 6.1 审计结论

| 审计对象 | 结论 | 是否可作为当前训练依据 |
|---|---|---|
| 最终教师 pair 图 | 内部排序质量强，但有 13 个零度节点 | 可以，节点口径修正为 9,987 |
| 离线 BT | held-out 指标、稳定性和负对照均通过 | 可以，用于数据质量审计和全局排序分析 |
| 行为数据清洗 V2 | 99.80% 原始记录可保留，未使用 `difficulty` | 可以，作为外部审计证据 |
| 行为 - BT 一致性 | 中等正相关，但 pair 覆盖仅 2.65% | 只能做复核与切片，不能替代教师标签 |

### 6.2 进入训练前必须完成

1. 从最终有效 pair 的端点重新导出 `active_train_questions.jsonl`，固定为 9,987 道题，并输出 13 个零度节点清单；
2. 对该 9,987 节点集合挂接 Aux11，运行覆盖率和类别质量审计；
3. 保留当前 `train_pairs.jsonl` 的 SHA256、最终 manifest 和本报告，作为训练数据版本的可追溯证据；
4. 启动完全同参的 `BT-only` 与 `BT + Aux11 (weight=0.03)` 对照训练。

### 6.3 选最终 checkpoint 前必须完成

必须构建并由教师独立打标 V4 validation pair。V3 validation 可以作训练过程中的临时监控，但其题池、特征契约与 V4 不完全一致，不能单独作为 V4 最终模型选择依据。

最终选择应以独立 V4 validation 的 soft pairwise log loss、Brier、AUC 和方向 accuracy 为主；Aux11 指标用于验证辅助任务是否学到可解释信息，但不能压过主 BT 目标。

### 6.4 当前不应做的事

- 不要将原始 `difficulty` 纳入训练、审计或阈值拟合；
- 不要因覆盖率而恢复被 `high_final_position_bias` 隔离的 pair；
- 不要因 64.21% 行为方向一致率就用行为数据替代 Qwen3-32B 教师打标；
- 不要把 BT 的训练内 97.61% accuracy 当作模型泛化指标或教育难度真值；
- 不要在没有 V4 validation 的情况下宣布某个 V4 checkpoint 为最终模型。
